# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.x.x   | :white_check_mark: |
| 4.x   | :x:                |
| < 4.0   | :x:                |

## Reporting a Vulnerability

Please use the private vulnerablity reporting system here on Github to report any security issues you may find with the pg_partman project. I will try to respond within 48 hrs to 
discuss how to move forward. Thank you for contributing to the project!
